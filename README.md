# 山东城建第三方校园枢纽（CampusHub）

一个把「山东城市建设职业学院」日常要用的几个入口收进同一个 App 的安卓客户端。

不是官方 App，也不是把官方 App 拆包重打包——它是一个**独立编写的原生客户端**：
能用接口的直接用接口，只能用网页的在 App 内置浏览器里打开，实在要原生能力（扫码、定位签到）的一键跳原版。

---

## 现在能做什么

| 模块 | 方式 | 说明 |
|---|---|---|
| 今日课表 | 原生接口 | 移动门户 `getSchedule`，首页卡片 + 课表页 |
| 未读 / 待办数 | 原生接口 | `getTabsJb` |
| 学籍资料 | 原生接口 | 姓名、班级、专业、系部（手机号/身份证打码显示） |
| 成绩 / 考试 | 内置网页 | 教务系统（正方 jsxsd） |
| 待办 / 会议 / 考勤 / 通讯录 / 一卡通 / 报修 | 内置网页 | 一站式服务大厅（CAS 单点登录） |
| 图书馆 / 校园邮箱 / 官网 / WebVPN | 内置网页 | — |
| 学习通 | 内置网页 | 打开即网页版，课程列表原生渲染（best-effort） |
| 今日校园 | 启动原版 | 该 App 有商业加固壳，不读它的内部数据 |
| 课表提醒 | 本地闹钟 | 每天 7:00 汇总 + 每节课前 15 分钟，**不依赖任何推送服务** |
| 通知聚合 | NotificationListener | 把上面几个 App 的通知汇总到首页，只读本机通知，不上报 |
| 深色模式 / Material You | 单包双 UI | Android 11 及以下走 M2，Android 12+ 走 M3 |

校园网状态（是否在校内）在「校园」页顶部显示，可手动重测。

## 环境要求

- Android 7.0（API 23）及以上
- 编译：JDK 17、Android SDK 34、Gradle 8.7

## 编译

```bash
# 1. 指向本机 SDK
echo "sdk.dir=/path/to/Android/sdk" > local.properties

# 2. 打包
gradle :app:assembleDebug      # 调试包
gradle :app:assembleRelease    # 正式包（未配签名时自动用 debug 签名）
```

推送与签名都是可选的：

- 没配 `keystore.properties` → 用 debug 签名
- 没配推送参数 → 首页显示「推送：未配置」，课表提醒照常工作

需要推送时按 [推送配置指南.md](./推送配置指南.md) 把参数写进 `local.properties`（HMS 走 `push.hms.appId`，FCM 走 `push.fcm.*` 四项）。

## 工程结构

```
app/src/main/java/com/scena/campushub/
├── Config.kt            地址、包名、校园网探测点
├── MainActivity.kt      4 个 Tab + 登录 + 网页壳
├── data/
│   ├── LysoftClient.kt  移动门户协议：RSA 协商 + AES-128-ECB + 登录 + 通用调用
│   ├── CampusApi.kt     课表 / 未读数 / 新闻
│   ├── CampusNet.kt     是否连着校园网
│   ├── CampusModule.kt  功能目录（网页类功能带 url）
│   └── Store.kt         会话与学籍本地存储
├── reminder/            本地课表提醒（AlarmManager + JobScheduler）
├── push/                推送双通道（HMS / FCM，配置驱动）
├── notify/              通知聚合（NotificationListenerService）
└── ui/                  功能宫格、课程行、弹窗
```

协议细节、接口可用性清单、踩过的坑，全部在 [项目审查与技术路线.md](./项目审查与技术路线.md)。
其中最值的两节：§4（移动门户协议全流程）和 §12（推送与提醒的实测结论）。

## 已知限制

- 移动门户只放行「课表 / 未读数 / 学籍」这几类接口，成绩、考试、待办不在这个网关上，
  所以这些功能是网页版而不是原生渲染。
- 学习通的课程列表解析是 best-effort：页面结构一变就可能读不到，此时仍可在网页版里正常使用。
- 今日校园有商业加固，本项目不尝试脱壳，任何数据都不读。
- 拍照签到、定位签到依赖原版 App 的原生 SDK 与服务端校验，网页端无法替代。
- 校内证书 `*.sduc.edu.cn` 的签发者没有下发中间证书，Android 不会自动补链。
  仓库里 `app/src/main/res/raw/sduc_ca.pem` 是**公开的中间证书**（TrustAsia DV TLS RSA CA 2025），
  只在 `network_security_config` 里对 `*.sduc.edu.cn` 补链，主机名校验仍由系统完成。
